Image Layout Modules

Drop-in image layout blocks for case study sections, plus the built-in case-study page modules (hero, three-column grid). Each includes a recommended export size (2× the largest on-screen render, crisp on retina) and a minimum (~1× — the floor for looking sharp on standard displays; fine to use when a source isn't available larger, but never upscale). Aspect ratio matters most: images use object-fit: cover, so match the listed ratio and the frame handles the rest.

Images: 1 Ratio: ~21:9 full-bleed Export: 2800 × 1200 Min: 1440 × 620 Class: .cs-hero

The masthead image at the top of a case study. Starts at content width and expands to full-page width as you scroll (driven by js/case-study.js), so export wide and high-res.
