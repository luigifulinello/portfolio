Image Layout Modules

Drop-in image layout blocks for case study sections, plus the built-in case-study page modules (hero, three-column grid). Each includes a recommended export size (2× the largest on-screen render, so it stays crisp on retina). Images use object-fit: cover, so match the listed aspect ratio and the frame handles the rest.
