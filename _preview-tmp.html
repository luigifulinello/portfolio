Four Ways to Paint

Before any of the export plumbing gets built, the tool needs to decide what it feels like to make something in it. Each of the four below is live — drag on the canvases, move the sliders, rewrite the code. The one that feels like painting to you is the one to build.

Shared by all four: 3840×2160 stills Seamless MP4 loops Frame · LG Gallery · ambient · USB

These aren't four options

Play with all four and the same thing keeps surfacing: three of them are really one architecture. A node graph is a way of arranging operations — so a hand-painted mask can be a node, and a block of your own code can be a node too.

That gives one tool with three doors into it. You open the app and patch boxes together, which needs no code. When you want to steer a system by hand, you drop in a Mask node and paint into it — the third demo, as one box in a graph. When a graph can't express what you want, you drop in a Code node and write the fragment yourself — the first demo, as one box in a graph. Nothing is thrown away as you get more comfortable; the surface just gets deeper.

Brush-based painting is the one to leave out. It's the largest build, it's the only one that doesn't compose with the others, and it makes the tool compete with Procreate on Procreate's terms.

Where that lands:

Graph engine → every node is a shader pass, resolution-independent by construction

Same graph renders 960×540 while you work, 3840×2160 on export

Loop nodes take a normalised time input, so a seamless MP4 is a render setting, not a feature

Frame / Gallery / ambient / USB are four export presets over one pipeline
