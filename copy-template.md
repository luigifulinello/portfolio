# Case Study Copy Template

Workshop copy here, then paste into the HTML files. Two variants below:

- **A — Standard arc** (matches `case-study-template.html` / `pdp-redesign.html`):
  Overview → Approach → Showcase → The Work → Reflection → Impact
- **B — Phased story** (matches `navigation-redesign.html`):
  Overview → Early Results → Problem deep-dive → Phased rollout → The Work → Takeaways → Close

Length guides come from the layout's actual line measures — treat them as targets,
not hard limits. Metadata rules per DESIGN.md: Company · Role · Focus · Team
(in-house framing, no Client/Services, no Timeline/Live).

# Voice & style crib sheet

- **First person, active**: "I set the roadmap…", not "the roadmap was set."
- **Metric-anchored**: every claim ties to a number or observable outcome where possible.
- **In-house framing**: Company/Focus language, never Client/Services.
- **Taglines & leads**: outcome-forward — say what changed, not what was done.
- **Approach statement**: one idea only. If it has an "and," cut it.
- **Captions**: noun phrase + em-dash + short description ("Buy box — always in reach").
- **Reflection**: judgment over output. What you'd repeat or avoid, not a recap.
